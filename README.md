# AI Business OS

AI Business OS 是一套将 AI 嵌入商业经营流程的方法、系统与数字资产。

## 项目模块

- business：商业战略与经营基础
- knowledge：知识库
- prompts：提示词资产
- workflows：业务工作流
- automation：自动化方案
- agents：AI 智能体
- playbooks：业务 SOP
- products：产品体系
- templates：标准模板
- assets：素材资源
- tests：测试与验证
- website：网站相关内容
- docs：项目文档
- scripts：脚本工具
